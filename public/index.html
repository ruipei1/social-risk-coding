A few useful distinctions

Code the behavior at issue. “I did not ask a question” still gets Asking a question. Choose more than one code when distinct behaviors matter.

Keep useful distinctions. Asking a question, expressing disagreement, and giving feedback are different behaviors.

Context is optional. Record who is involved and the setting only when supported. Leave missing details unspecified.

Keep the prompt labels. Approach and Avoid come from the survey. Declining an invitation can itself be a social risk; note contradictions in Observations.

Use Observations for uncertainty. Note alternative meanings, contradictions, or stated stakes. Use Needs discussion when another reader would help.

Starting codes are provisional. Add a name when a useful behavior is missing; saving shares it with the team.
